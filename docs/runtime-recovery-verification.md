# Runtime and recovery tool verification

Verified on Windows with installed Python3.11 and Windows PowerShell5.1 on2026-10-17. The generic runtime prototype passed29 offline fixtures: real mutex/exclusive-handle and five-controller race, one review/two QA capacity, exact process identity/path checks, stale/reused/ambiguous state, owner-specific release, exclusive receipt persistence, default/explicit dry-run through actual CMD/PowerShell, malformed resource rejection and trailing-backslash round-trip through the Windows argument parser. Native executable files were deliberately non-executable fixtures. CIM queried only the running test's own Python helper. No game, live registry, user profile, OS focus or input was used.

The recovery helper ran14 fixtures:13 passed and the actual external-symlink metadata fixture was skipped because this Windows shell cannot create symlinks. Ordinary-file/root-containment checks apply to payload files, checkpoint.json and COMPLETE; a separate boundary fixture verifies that reserved metadata takes the guarded path. Round-trip identity, mutation/missing/extra files, wrong external digest, incomplete output, existing destinations, case-insensitive duplicates, uppercase JSON private keys, signed links in files/metadata, unsupported raw assets/provenance and duplicate JSON were exercised.

An actual private source checkpoint was also committed, bundled, cloned into a second empty checkout and verified against an independently recorded manifest digest. Project code, private indexes, bundle, owner receipts and large artifacts are not included in this public repository. This demonstrates that recovery path for the bounded source/text snapshot, not a complete restored native environment.

Independent source review identified and prompted the metadata containment, scalar argv and receipt-output hardenings. The reviewer did not rerun native tests. Simultaneous native rendering/resource use, migration into an existing project and physical gameplay remain unqualified. Existing client/server launchers are unchanged, and the new prototype's migration remains disabled.
